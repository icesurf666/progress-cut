# ProgressCut Brand Spec

## Direction

**Dark Japanese Editorial Devtool**

ProgressCut should feel:

- precise
- quiet
- technical
- cinematic
- premium
- open-source
- developer-first

Avoid:

- generic AI SaaS visuals
- excessive gradients
- playful startup illustrations
- obvious play-button branding
- anime-character branding
- cyberpunk overload
- glassmorphism everywhere

---

## Primary visual concept

The identity is based on:

- dark graphite surfaces
- off-white typography
- violet accent
- geometric panels
- a diagonal “cut” motif
- restrained Japanese editorial influence

The logo should represent:

> many visual states being reduced into a few meaningful story moments

The diagonal slash is a recurring visual motif representing selection/cutting/compression.

---

## Colors

```css
--bg: #09090b;
--surface: #111114;
--surface-raised: #17171b;

--text-primary: #f4f4f2;
--text-secondary: #9a9aa2;

--violet: #8b5cf6;
--violet-light: #c4b5fd;
--violet-deep: #6d3ef2;

--success: #b7ff5a;
```

The violet accent should be used sparingly.

The lime/success color must only be used for:

- success
- active capture state
- benchmark PASS
- completed state

Do not use lime as a primary branding color.

---

## Typography

Primary UI typography:

- Inter
- Satoshi
- Geist

Preferred feel:

- clean
- modern
- dense enough for developer tools
- not overly rounded

Japanese text is a secondary decorative/editorial layer, not core UI copy.

Possible brand line:

```text
プログレスカット
```

Use Japanese text only in:

- splash screen
- README hero
- about page
- launch graphics
- branded illustrations

Do not use Japanese labels for important controls.

---

## Logo system

Primary mark:

- 2–3 vertical geometric panels
- a diagonal slash/cut
- no generic play button

The mark must work in:

- 16×16
- app icon
- GitHub avatar
- README
- desktop title bar
- monochrome version

Wordmark:

```text
ProgressCut
```

Recommended treatment:

```text
Progress      → off-white
Cut           → violet
```

Secondary lockup:

```text
ProgressCut
プログレスカット
```

---

## Layout language

Use:

- large negative space
- thin dividers
- restrained grid
- clean alignment
- small uppercase labels
- compact metrics
- editorial spacing

Example:

```text
SESSION

04:12:18
duration

8,214
observations

1,183
meaningful changes

247
story moments
```

---

## UI principles

The UI should feel like a serious developer tool.

Prefer:

- flat surfaces
- subtle borders
- strong typography
- small amounts of violet
- clear hierarchy

Avoid:

- large cards everywhere
- heavy shadows
- excessive blur
- neon gradients
- decorative animation without purpose

---

## Tone of voice

Tone:

- calm
- technical
- concise
- confident

Good:

```text
5h 12m of coding → 58s of progress.
```

```text
8,214 observations.
1,183 meaningful changes.
247 selected moments.
```

```text
Turn progress into stories.
```

Avoid:

```text
Create magic with AI
```

```text
Transform your workflow instantly
```

```text
Revolutionary productivity
```

---

## Product tagline

Primary:

> **Turn progress into stories.**

Alternative:

> **Hours of work. One minute worth watching.**

Developer launch line:

> **Turn hours of coding into a one-minute build story. Automatically.**
